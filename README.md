# ZenLedger | Daily CA Utility

ZenLedger is a lightweight, browser-based Progressive Web App (PWA) designed for Chartered Accountants, Tax Consultants, GST Practitioners, small businesses, and students. It provides essential tax calculators, compliance tracking, and client management in one place.

## 🌐 Live Demo

https://parmindrsingh1.github.io/ZenLedger/

## ✨ Features

- GST Calculator
- Income Tax Calculator
- TDS Calculator
- Due Date Tracker
- Client Manager
- Import / Export (JSON, CSV, Excel)
- Offline Support (PWA)
- Responsive Design
- Local Data Storage

## 🔒 Privacy

- No login required
- No cloud storage
- No user tracking
- Data remains in your browser using LocalStorage

## 🛠 Technology Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- LocalStorage
- Progressive Web App
- GitHub Pages

## 📱 Progressive Web App

- Installable on desktop and mobile
- Offline functionality
- App Manifest
- Service Worker

## 🚀 Getting Started

1. Clone the repository
2. Open `index.html` in a browser
