# 📊 ZenLedger | Daily CA Utility

ZenLedger is a lightweight, browser-based Progressive Web App (PWA) designed for Chartered Accountants, Tax Consultants, GST Practitioners, small businesses, and students. It provides essential tax calculators, compliance tracking, and client management in one place.

🌐 **Live Demo:** https://parmindrsingh1.github.io/ZenLedger/

---

## ✨ Features

- 🧾 GST Calculator
- 💰 Income Tax Calculator
- 📑 TDS Calculator
- 📅 Due Date Tracker
- 👥 Client Manager
- 📤 Export Clients (JSON, CSV, Excel)
- 📥 Import Clients (JSON)
- 🔍 Duplicate GSTIN & PAN Validation
- ℹ️ About Section
- 📱 Progressive Web App (PWA)
- 🌐 Offline Support

---

## 🚀 Installation

Clone the repository:

```bash
git clone https://github.com/parmindrsingh1/ZenLedger.git
```

Open `index.html` in your browser.

Or visit the live demo.
